# Experiment-Driven Research Agent

An Agent Skills-format package for turning a research topic into a literature-grounded, experimentally evaluated scientific study and manuscript.

## What it is designed to do

- Structure a research question, literature review, and gap analysis.
- Plan mathematically grounded methods and reproducible experiments.
- Track datasets, baselines, configurations, metrics, and raw outputs.
- Analyze results and limitations without inventing evidence.
- Organize a manuscript for IEEE Access or another specified Q1 journal.

## Important operating rule

This skill provides instructions, not guaranteed compute, data access, subscriptions, or experimental results. The agent must distinguish completed experiments from proposed work, cite verifiable sources, report failed runs and limitations, and never fabricate citations, measurements, or claims.
